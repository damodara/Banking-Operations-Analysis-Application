# Banking Operations Analysis Application

Приложение для анализа банковских операций, которое обрабатывает данные транзакций из Excel-файла и предоставляет различные сервисы для анализа финансовых данных.

## Функциональность

### Веб-страницы
- **Главная страница** - отображает приветствие, информацию по картам, топ транзакций, курсы валют и цены акций
- **Страница событий** - показывает расходы и поступления за выбранный период

### Сервисы
- **Выгодные категории повышенного кешбэка** - анализ наиболее выгодных категорий для кешбэка
- **Инвесткопилка** - расчет суммы для накоплений через округление трат
- **Простой поиск** - поиск транзакций по описанию или категории
- **Поиск по телефонным номерам** - поиск транзакций с мобильными номерами
- **Поиск переводов физическим лицам** - поиск переводов физлицам

### Отчеты
- **Траты по категории** - анализ трат по конкретной категории за 3 месяца
- **Траты по дням недели** - средние траты по дням недели
- **Траты в рабочий/выходной день** - сравнение трат в рабочие и выходные дни

## Установка и запуск

1. Клонируйте репозиторий
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env_template` в `.env` и заполните необходимые переменные
4. Запустите приложение:
   ```bash
   python main.py
   ```
